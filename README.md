## How I build

I work spec first. I write down what the thing has to do before there is any code, build
it with AI assistance, then go through every flow by hand on a real device and fix what
breaks before it ships.

What I own is the problem and the verification. I decide what gets built and what it
should do, and I am the one who finds out something is broken before a user does. The
café system has been taking real orders since the day it went in, which is a different
kind of test from a demo.

Ask me about anything on this page and I can tell you how it works, why it is built that
way, and what I would change next. I am reading and writing more of the code myself as I
go.
